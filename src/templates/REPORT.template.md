# Журнал отчётов по задачам

Секция на каждую завершённую задачу, только дописывается в конец — см. `AGENTS.md`, раздел
«Отчётность и статус», формат секции.

**Архивация (ответственность оркестратора, не исполнителя):** когда крупный пункт Roadmap в
`PLAN.md` помечается ✅ done, оркестратор переносит текущие `REPORT.md`/`LOG.md` в
`reports/REPORT-phase-N-<имя>.md` / `reports/LOG-phase-N-<имя>.md` (номер и имя — по пункту
Roadmap), и создаёт новые пустые `REPORT.md`/`LOG.md` из этих шаблонов для следующей фазы. Это
не теряет историю (она остаётся в `reports/` и в git), но не даёт активным файлам расти
неограниченно на длинной дистанции проекта.
